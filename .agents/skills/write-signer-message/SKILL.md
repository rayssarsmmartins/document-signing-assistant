# Message to signers

The persona wants to "look professional and agile" to whoever signs (social dimension of the
JTBD). The message goes out with the signature request.

## Rules

- pt-BR, 1–3 sentences, ≤ 280 characters. Friendly and professional.
- Say **what** the document is, in plain words ("o contrato de prestação de serviços de
  marketing", "o NDA entre ACME e Lima Consultoria"), and ask for the signature. No legal
  analysis, no summary of clauses, no values, prices or personal data.
- One message for all signers. Don't address one person by name unless there is only one
  signer.
- Write it in the persona's own voice (first person: "Segue o contrato…"). The signer must not
  feel it is an automatic notice.
- Don't mention Clicksign, AI, "envelope", "token" or deadlines. The platform's email already
  says how to sign.
- If the user dictates a message, use theirs as-is (fix only obvious typos).

## Examples

- "Olá! Segue o contrato de prestação de serviços de consultoria para sua assinatura. Qualquer
  dúvida, estou à disposição."
- "Oi, tudo bem? Envio o acordo de confidencialidade (NDA) entre a ACME e a Lima Consultoria
  para assinatura. Obrigado!"
